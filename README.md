# Colorful Speed Clicker Game

A simple and fun reaction training game built with Python and Tkinter. The objective is simple: click the numbers in ascending order (starting from 1) as fast as you can!

## Features

* **Two Difficulty Modes:**
    * **3x3 (Easy):** Numbers 1 to 9.
    * **4x4 (Hard):** Numbers 1 to 16.
* **Colorful Interface:** 16 unique pastel colors that randomize every game.
* **Timer:** Tracks your reaction time with millisecond precision.
* **Visual Feedback:** Buttons change appearance when clicked correctly.

## Prerequisites

* **Python 3.x**
* **Tkinter** (Standard Python GUI library)
